# 0.5.0 润色工作台

本版需重新部署后端，前端入口仍只有魔法棒菜单。

## 功能

四个顶部页签：连接、预设、提示词、正文。保留日夜模式、自定义模型收藏、预设条目开关。

正文页读取最新 AI 回复，提供原文、纯文本可编辑结果、柔和黄色新增/红色删除线差异、原文/上一版比较、草稿版本选择（最近10版）、复制结果、继续修改。继续修改发送初始原文作为事实参考＋当前草稿＋追加要求，不无限携带历史。默认输出8192，可在连接页调至32768；模型能力/思考消耗仍可能限制输出。截断草稿不允许直接替换。

提示词页分长期要求和本次补充。可以不调用 AI 先组装并查看发送内容；继续修改的实际请求在发起后同步显示在该区域。该视图含私密正文，不含访问口令。

切换聊天会取消正在进行的请求并阻止旧结果写回，但已经得到的草稿仍留在内存。确认替换核对原消息与swipe。刷新页面会丢失草稿，使用复制结果备份；本版没有后台持久化草稿、下载草稿、分段处理、暂停恢复。

## 长文

前后端合计输入限制100000 UTF-16字符，请求体1MiB，后端Vertex等待180秒，前端240秒，Cloud Run300秒。字符数不是token数，不能保证100000字可完整输出。输出仍受Google模型限制，32768可能被某些模型拒绝；建议先用8192。继续修改同时携带原文和草稿，总输入也计入限制。

## 诊断

后端返回HTTP、上游HTTP、Google白名单状态、模型、区域、requestId和固定建议。刻意不回传Google原始错误文本，避免输入或秘密被错误回显。前端错误区显示安全摘要并提供复制脱敏诊断，不复制正文或口令。

## 验证与边界

已运行54项Node模拟/本地HTTP测试和JS语法检查。涵盖差异重建、继续修改请求与版本、预设、认证、长文100000边界、上游错误脱敏。没有真实酒馆浏览器、APK、Google凭据；CSS视觉效果、键盘、浏览器原生dialog的布局需用户验证，不能把模拟UI断言当截图验收。

差异算法对小变更做字符级LCS，对大变更退化为公共前后缀＋整块新增/删除，避免巨大矩阵卡顿；因此长文高亮可能较粗，不是完美语义diff。继续修改是新付费请求，不会自动重试。
